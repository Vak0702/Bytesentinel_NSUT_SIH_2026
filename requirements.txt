# BEFORE YOU RUN THIS: two libraries pip cannot install

# Both are native (C/C++) libraries that Python packages below link against at
# runtime. Missing either produces an ImportError that LOOKS like a missing pip
# package but is not -- reinstalling the Python package will not help.
#
#   1. Microsoft Visual C++ 2015-2022 Redistributable (x64)
#      Needed by: onnxruntime (which insightface and mrzscanner both sit on)
#      Symptom:   ImportError: DLL load failed while importing
#                 onnxruntime_pybind11_state
#
#   2. libjpeg-turbo  (Windows: VC 64-bit installer, default C:\libjpeg-turbo64)
#      Needed by: PyTurboJPEG, pulled in transitively by mrzscanner
#      Symptom:   RuntimeError: Unable to locate turbojpeg library automatically
#

# --------------------------------------------------------------------------
#   PaddleOCR   -> ~/.paddlex        detection + recognition models
#   InsightFace -> ~/.insightface    buffalo_l face model
#   mrzscanner  -> site-packages     MRZ detector + a CJK font
